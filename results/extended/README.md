# Extended AMQ benchmark results (Phases 2 and 3)

The original Phase-1 results remain in the parent `results/` directory. The
Phase-2 and Phase-3 experiments are stored here, with raw per-repeat CSVs,
aggregated CSVs, configuration snapshots and plots. Generated binary input
workloads are excluded from the package and are regenerated by the scripts.

## Phase 2: CQF algorithmic and paper-scale work

- `hash_modes.csv` / `hash_modes_raw.csv`: three CQF hash modes on the
  996,148-operation control, with deletion included.
- `hash_modes_67m.csv` / `hash_modes_67m_raw.csv`: the same modes at 67M;
  deletion is `NA` because this extension measured insertion/lookup/FPR paths.
- `paper_scale_1_256.*`, `paper_scale_1_512.*`, `paper_scale_1_1024.*`: 67M
  CQF/Cuckoo/Bloom comparisons at three target FPRs.
- `paper_scale_highload_1_512.*`: supplementary approximately 95%-occupancy
  CQF point at 63,753,420 operations.
- `scale_comparison*`, `cqf_load_factor_*`, and
  `paper_scale_fpr_sweep_*`: scale, occupancy and target-FPR analyses.

See `EXPERIMENT_NOTES.md` and `STATUS.md` for the Phase-2 setup and findings.

## Phase 3: seven-filter comparison

The new filter implementations are Counting Bloom, Blocked Bloom, XOR and a
scalar Binary Fuse-style filter. Combined with CQF, Cuckoo and standard Bloom,
the unified result table contains 14 rows (seven filter families by uniform
and Zipfian workloads).

The primary completed run is tagged `expanded_phase3_1m_1_512_v2`:

- one million insertion operations per distribution;
- one million negative queries per distribution;
- target FPR 1/512;
- three timing repetitions;
- 24 raw added-filter rows, eight added-filter aggregate rows, and a 14-row
  unified table;
- ten combined throughput, latency, deletion, memory and FPR plots.

The three 100k single-repeat FPR parameterization checks are tagged
`phase3_validation_fpr_1_256`, `phase3_validation_fpr2_1_512` and
`phase3_validation_fpr2_1_1024`.

See `PHASE3_STATUS.md` for the numerical summary, implemented operation
support, validation record, limitations and follow-up candidates. See the
repository-root `FILTER_CATALOG.md` for the detailed algorithms, shared
protocol, citations and why InfiniFilter, Maplets, Adaptive Quotient Filters
and GPU-oriented filters are proposed for later extensions rather than being
misrepresented as drop-in standalone filters here.

## File naming

- `*_raw.csv`: individual repeat observations.
- Matching `.csv` without `_raw`: repeat-averaged rows.
- `*_configuration.txt`: parameters, distinct counts, filter sizing and input
  metadata.
- `*.png`: generated plots from the corresponding result tables.

The same deterministic negative-query sample is reused across timing repeats.
Those repetitions improve timing estimates but are not independent samples
for a statistical confidence interval on FPR.
